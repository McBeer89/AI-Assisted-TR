# Offline TRR & DDM Research Guide

A standalone reference for producing Technique Research Reports and Detection
Data Models following the TIRED Labs methodology — without AI assistance.

Based on the TIRED Labs methodology developed by Andrew VanVleet.

## How to Use This Guide

1. Read **Section 2 (Core Concepts)** first — internalize before starting.
2. Complete **Section 3 (Pre-Research)** while you still have internet access.
3. Follow **Sections 4-8** in order, respecting the phase gate checkpoints.
4. Use the **Appendices** as quick-reference during work.

Do not skip phases. Do not advance past a checkpoint until it's satisfied.
